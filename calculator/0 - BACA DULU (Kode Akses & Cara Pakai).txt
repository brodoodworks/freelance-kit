---------------------------------------------------------
CARA 1 — PAKAI DARI ZIP INI (disarankan, bisa offline)
---------------------------------------------------------
1. Ekstrak/unzip semua isi ZIP ini ke folder di komputer
   atau HP kamu (misalnya folder Documents/Downloads).
2. Buka file "Freelance Kit.html" — klik/tap dua kali,
   otomatis kebuka di browser. Tidak perlu instalasi apa pun.
3. Saat muncul layar "Masukin kode akses", ketik kode di
   atas, lalu tekan tombol "Buka Aplikasi / Unlock".

Kode hanya perlu dimasukkan SEKALI per perangkat/browser.
Setelah itu aplikasi langsung kebuka tiap kali dipakai lagi.


---------------------------------------------------------
CARA 2 — KALAU KESULITAN EKSTRAK/BUKA FILE ZIP
---------------------------------------------------------
Kalau ekstrak ZIP terasa ribet, kamu bisa langsung pakai
lewat link ini di browser HP atau komputer (tidak perlu
extract apa-apa):

    https://brodoodworks.github.io/freelance-kit/calculator/

Buka link itu, lalu masukkan kode akses yang sama seperti
di atas. Setelah kode dimasukkan, halaman ini juga bisa
di-"Install as App" dari menu browser supaya kebuka seperti
aplikasi biasa dan bisa dipakai offline.

Catatan: data yang kamu isi di versi link ini dan versi ZIP
tersimpan TERPISAH di masing-masing browser (kecuali kamu
aktifkan fitur Sinkronisasi Antar Device di menu Pengaturan).
Disarankan pilih SATU cara saja (ZIP atau link) supaya data
kamu tidak tercecer di dua tempat.
